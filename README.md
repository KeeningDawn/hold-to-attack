# Hold to Attack

## Purpose

Remember the old Jeb Combat Snapshot that you had to manually install? It had a "Hold to Attack" feature, where holding left click (or your attack button) would continue swingin for you, so long as an entity stayed in the crosshair.

Do you wish it was still part of the game? Me too.

Are you sad that you have to keep finding a new mod for this feature every update? Same.

## Disclaimer

Use at your own risk. Some servers may consider this mod an unfair advantage (cheating.)

Ask the server's staff team prior to using this mod in multiplayer.
