# Hold to Attack

## Purpose

Remember the old Jeb Combat Snapshot that you had to manually install? It had a "Hold to Attack" feature, where holding left click (or your attack button,) would continue swinging for you, so long as an entity stayed within your crosshair.

Do you still wish it was part of the game? Me too.

Are you sad that you have to keep finding a new mod for this feature every few updates? Same.

Were you disappointed that some of them allowed attacking when it's impossible in vanilla? Relatable.

Even more annoyed when they'd let it rip when cooldowns are disabled? Twins.

## Features

- Hold the attack button to continue attacking when fully charged.
    - Supports optional jitter variance (off by default) with adjustable ranges (10~50ms by default.) Requires Mod Menu to enable/adjust.
    - Hardcoded cap of ~16 attacks per second when attack cooldowns are disabled.
- Toggle the mod with a hotkey, or in Mod Menu.

## Disclaimer

Use at your own risk. Some servers may consider this mod an unfair advantage (cheating.) Servers that do not allow an auto clicker will not allow this mod. They achieve similar end-results.

Ask the server's staff team prior to using this mod in multiplayer.
